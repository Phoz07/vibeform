# Vibe Form

AI-assisted form builder that guarantees respondent privacy by physically isolating form definitions (Control Plane) from form responses (Data Plane) at the infrastructure level.

## Language

### Core Architecture

**Control Plane**:
The subsystem (API Worker bindings, MCP Worker, and `definitions-db`) responsible for form lifecycle and schema definitions.
_Avoid_: Management plane, admin service

**Data Plane**:
The subsystem (API Worker bindings, `responses-db`, and attachments R2 bucket) responsible for storing respondent answers and files.
_Avoid_: Storage plane, submission backend

### Actors

**Owner**:
An authenticated user who creates, edits, publishes forms, and reviews submitted responses.
_Avoid_: Admin, creator, user

**Respondent**:
An anonymous or identified end-user submitting data via a public form link.
_Avoid_: Submitter, visitor, client

### Security & Tokens

**MCP Token**:
A high-entropy secret (stored as a SHA-256 hash in `definitions-db`) generated by an Owner to grant an AI agent scoped access (`forms:read` or `forms:write`) to the Control Plane.
_Avoid_: API key, session token, bot secret

**Publish Gate**:
The mandatory human-in-the-loop verification step required to transition a form from `draft` to `published`, enforced exclusively on the Web Dashboard.
_Avoid_: Approval flow, activation check

### Domain Entities

**Form Definition**:
The schema and metadata defining a form's title, fields, status, and vibe, accessible by AI via MCP.
_Avoid_: Form template, form config, form model

**Form Response**:
An individual submission record containing answers and optional attachments submitted by a Respondent, stored strictly in the Data Plane.
_Avoid_: Submission, entry, record

**Field**:
A single interactive question or input element within a Form Definition with an immutable ID and type.
_Avoid_: Input, question, item

**Field Config**:
The type-safe polymorphic configuration payload (options, bounds, validation rules) for a specific field type.
_Avoid_: Field options, field params, field json

**Form State**:
The publication status of a form: `draft` (editable, not accepting responses), `published` (accepting responses), or `closed` (archived, not accepting new responses).
_Avoid_: Status, lifecycle

**Slug**:
The public URL identifier for a published form (`/f/:slug`), initialized to a collision-resistant NanoID and optionally customizable by the Owner.
_Avoid_: Vanity URL, path, form address

**Vibe**:
The visual and stylistic design configuration tokens (curated presets and whitelisted attributes: `primaryColor`, `backgroundColor`, `borderRadius`, `fontFamily`) assigned to a form.
_Avoid_: Theme, styling, template, custom CSS

**Cleanup Cascade**:
The synchronous teardown sequence (R2 attachments -> `responses-db` -> `definitions-db`) executed by the API Worker when a form or response is deleted.
_Avoid_: Hard delete, purge, wipe
